KYVAAN GROUP — Brand film
=======================

Drop the final brand film into this folder as:

    public/media/hero-kyvaan.mp4

The hero already references ./media/hero-kyvaan.mp4 (muted, looping,
autoplay where policy allows). While the file is absent, the hero
gracefully shows the high-quality poster image — the page never blocks.

Recommended: 1920x1080 or higher, H.264, muted-friendly, 10–20 s seamless loop.
