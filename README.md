# KVAAN GROUP — Advanced Real Estate Website

Static HTML/CSS/JS website prepared for GitHub + Vercel.

## Run locally
Open `index.html` in a browser, or use any static server.

## Deploy with GitHub + Vercel
1. Create a GitHub repository.
2. Upload `index.html`, `assets/`, and this README.
3. Import the repository into Vercel.
4. Framework preset: **Other** (or leave Vercel to detect a static site).
5. Build command: leave empty.
6. Output directory: `.`
7. Deploy.

## Add future projects
- Project cards are in `index.html` under `#projects`.
- Branch content is in the `data` object near the bottom of the file.
- Add a new `.branch` button + SVG branch if you want another division.
- Replace the images in `assets/` with your real project photography while keeping the filenames, or update the image paths.

## Form
The enquiry form is intentionally frontend-only. Connect it later to your preferred CRM, email API, Formspree, Resend, or custom backend.
